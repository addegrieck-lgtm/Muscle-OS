# LUMÉANCE — consignes pour Claude

- Projet autonome dans le dépôt Muscle-OS : Next.js 15 (OpenNext) sur Cloudflare Workers,
  Supabase. Voir `README.md` et `docs/`.
- **Nouvelle pièce ou modification d'une fiche produit : suivre `docs/FICHE-PRODUIT.md`**,
  modèle validé par le propriétaire (photos du fournisseur rendues plus nettes en premier, puis
  la visualisation 3D de la version choisie ; pas de mise en situation 3D).
- Ne jamais inventer de caractéristique, de certification ou de stock ; ne jamais effacer un
  filigrane.
- Vérifier avant de proposer une fusion : `npm run check` et `npm run test:db`.
