# Récap — Business plan mono-produit

> Résumé du texte source : [MONO_PRODUIT_TEXTE_ORIGINAL.md](./MONO_PRODUIT_TEXTE_ORIGINAL.md).

## L'idée en une phrase

Appliquer les techniques agressives des dropshippers (mono-produit, une page par angle, pub massive) à un **produit réellement meilleur** (private label, comparé à 70+ concurrents), sur un marché dominé par des grosses marques peu agiles (« les boomers de l'e-com »).

## Les briques du système

| Brique | Rôle |
|---|---|
| **Un seul produit** | Un stock à financer, une offre à optimiser, une seule question à valider. La gamme viendra après. |
| **Offre (méthode Hormozi)** | Rendre le « non » absurde : bonus > prix, risque supprimé. |
| **Accessoire** | Faible coût, forte valeur perçue, visible en usage. Rarement vendu seul : sert à rendre les packs irrésistibles. |
| **3 packs** | **Solo** (1 produit, rien d'autre) · **Duo** (2 produits + accessoire + livraison + membre à vie, coché par défaut) · **Binôme** (3 produits + 2 accessoires + 2 accès membre, dont un à offrir). Objectif : faire passer du Solo au Duo. |
| **Upsell 1 clic** | Solo → 2ᵉ produit réduit (débloque tout) ; Duo → Binôme ; Binôme → +1 produit. Jamais de produit bradé après un Duo (repousserait le rachat). |
| **Garantie** | 30 jours, même entamé, le client garde produit + accessoire. |
| **Application mobile** | Pièce maîtresse (voir ci-dessous). |
| **Statut membre** | Le pont entre produit et app : app complète + prix membre exclusif dans la boutique de l'app. |
| **Créateurs** | Micro-créateurs (< 10k abonnés) = usine à contenus pub. |
| **Site en 2 couches** | Vitrine (marque, recrutement créateurs, organique) + pages d'angle (hors menu, hors Google, trafic payé, mobile-first). |

## L'application : 4 rôles

1. **Cadeau qui fait passer au Duo** — l'app seule vaut plus que le Duo ; elle coûte quasi rien par client.
2. **Caisse du rachat** — boutique membre intégrée, prix inférieur au site, achat à l'unité. Aucune notification commerciale.
3. **Crédibilité** — une marque avec sa propre app ≠ shop monté en un week-end.
4. **2ᵉ canal d'acquisition** — app plus belle et plus simple que la concurrence (9 écrans au lieu de 16), usage quotidien gratuit, le reste derrière un paywall qui propose : abonnement (volontairement cher) **ou** Duo/Binôme avec abonnement offert à vie. Partage de cartes gratuit, sans jamais afficher le produit.

## Les 5 portes pour devenir membre

1. Duo/Binôme sur le site → code par email → membre à vie.
2. Duo acheté dans l'app (paywall/boutique) → sans code.
3. Code créateur → pas de remise, mais du « membre » : 1 an sur un Solo, un accès à vie à offrir sur Duo/Binôme.
4. Code offert par un ami (Binôme ou code créateur).
5. Abonnement payant dans le paywall (peu intéressant face à l'offre produit).

## La boucle client

Achat Duo/Binôme → code membre par email → usage quotidien de l'app → produit fini → **rachat dans l'app au prix membre (sans coût pub)** → le pote du Binôme découvre l'app et devient client.

> La pub fait entrer un client une fois. L'app le fait revenir.

## Acquisition : full ads, « pay to win »

- Année 1 : quasi 100 % pub payante ; organique/SEO plus tard.
- **Un angle = une pub = une page.** Jamais de pub vers l'accueil (26 concurrents sur 27 étudiés font pareil, via Trendtrack).
- Choix des angles : vraie douleur client + preuve incontestable. Angle validé chez un concurrent = > 90 jours, > 10 variantes, page dédiée.
- Test : **4 angles max**, quelques milliers d'euros → garder le meilleur angle → garder les meilleures pubs → scaler. Paliers vidéo : test (accroche) → validé (coût par achat) → scale.
- **Rentabilité** : viser l'équilibre (voire légèrement en dessous) au premier achat ; la marge vient du rachat. Objectif année 1 : gros CA et portée maximale.

## Programme créateurs

- Contrepartie demandée : vidéos sur les angles fournis, sans script imposé, + droits pub sous leur nom.
- Rémunération : produit + membre à vie, réassort mensuel si assez de vidéos, code perso avec commission, petite commission sur les ventes de leurs vidéos en pub, primes par palier de vues organiques, place dans la vitrine du site.
- Boucle : post → test pub petit budget → montée si accroche → scale si vente → plus de créateurs = plus de gagnantes.

## Logistique

Expédition à la main au début. Si démarrage fort sur les 2 premiers mois : commande ×10 au fournisseur et passage en 3PL. Cible : le million, sans prévision mensuelle inventée.

## Reste à faire avant le lancement (janvier)

- Brancher paiement, emails, comptes pub.
- Recevoir le stock.
- Écrire et automatiser la séquence email (post-achat → rachat).
- Signer les créateurs avant le lancement.
- Produire les créas vidéo sur les angles choisis.
- Finir les pages d'angle (80 %).
- Publier l'app avant janvier (90 %) pour capter du trafic et éliminer les bugs.
- Décembre = grosse phase de test.

## Risques identifiés

- **Rachat non prouvé** — toute la rentabilité en dépend.
- **Rupture de stock** — une vidéo virale peut vider le premier lot.
- **Validation des stores** — lier un achat physique à un accès in-app est délicat.

## Philosophie finale

Produit au centre, offre qui pousse au pack, app qui fait revenir, statut membre qui relie, pub qui trouve l'angle, créateurs qui fournissent la matière. Si ça échoue, on change tout **sauf le produit** : « tout se vend » — l'échec viendrait de l'écosystème construit autour, pas du produit.
