# Modèles de configuration du serveur Minecraft

Extraits à **fusionner** dans les fichiers générés par Paper 1.21 (une clé absente garde sa valeur par défaut). Explications, plugins recommandés et liste de contrôle : [docs/MINECRAFT_PERFORMANCE.md](../../docs/MINECRAFT_PERFORMANCE.md).

| Fichier | Destination sur le serveur Minecraft |
|---|---|
| `start.sh` | racine du serveur (`MEM=12G ./start.sh`) |
| `server.properties` | `server.properties` |
| `spigot.yml`, `bukkit.yml` | racine du serveur |
| `config/paper-global.yml`, `config/paper-world-defaults.yml` | dossier `config/` |
